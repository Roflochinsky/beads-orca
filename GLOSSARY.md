# Beads for Orca

Плагин связывает задачи Beads с рабочим пространством Orca. Desktop-приложение Beads HUD — отдельный продукт, не вариант установки этого плагина.

## Language

**Плагин Beads для Orca**:
Расширение Orca для работы с задачами Beads внутри редактора.
_Avoid_: Сборка Orca, отдельное Beads desktop-приложение.

**Задача Beads**:
Единица работы, сведения о которой, зависимости и состояние ведёт Beads.
_Avoid_: Агентская сессия, поручение агенту.

**Workspace Orca**:
Рабочее пространство Orca, к которому относятся открытые файлы и работающие агенты.
_Avoid_: База Beads, агент.

**CLI-сессия агента**:
Отдельный сеанс работы агента в терминале workspace Orca. Две открытые сессии Codex — два разных адресата, даже если они используют один инструмент.
_Avoid_: Установленный провайдер, задача Beads, встроенный чат Orca.

**Удалённый workspace Orca**:
Workspace, файлы и выполнение команд которого находятся на другом хосте относительно приложения Orca пользователя.
_Avoid_: Локальная копия проекта, локальный каталог с таким же путём.

**Пул задач**:
Выбранный пользователем набор задач для передачи одному или нескольким исполнителям.
_Avoid_: Автоматическая очередь, сохранённый фильтр.

**Поручение**:
Набор задач с контекстом и ожидаемым результатом для одной агентской сессии в указанном workspace. Пул можно вручную разделить на несколько поручений.
_Avoid_: Задача Beads, агентская сессия.

**Передача поручения**:
Отправка поручения выбранному адресату. Передача сама по себе не означает принятия задач в работу или их завершения.
_Avoid_: Claim, выполнение задачи.

**Сохранённый фильтр**:
Именованные условия динамического представления задач.
_Avoid_: Зафиксированный список задач, автоматическая очередь.

**История передач**:
Сведения о поручениях, адресатах и подтверждённых событиях передачи.
_Avoid_: История всех изменений задач Beads, список выполненных задач.

**Исполнитель поручения**:
Конкретная агентская сессия, которой адресована работа. Параллельные сессии одного типа агента — разные исполнители.
_Avoid_: Общее имя провайдера, аутентифицированная личность.

**Артефакт поручения**:
Явно подготовленный контекст или отчёт, относящийся к одному поручению.
_Avoid_: Вся личная история, автоматически опубликованный отчёт.
